Getting Started

Jump to: What is this app? Prerequisites First Launch Adding Applicants AI Reviews Manual Reviews Next Steps
1

What is This App?

The Admissions Application Review Assistant helps university admissions teams manage and evaluate applicant profiles. It combines manual reviewer assessments with AI-powered analysis to provide thorough, consistent reviews.

Key capabilities:

  • Centralized applicant database with status tracking
  • AI-powered reviews via the Kindo agent platform
  • Manual review forms with structured scoring
  • Dashboard with pipeline overview
2

Prerequisites

Before you begin, make sure you have:

  • An account — register on the login page or use the default admin credentials (username: admin, password: admin).
  • Kindo API access (optional) — for AI-powered reviews, you need a Kindo API key and an agent ID. Set them as environment variables (KINDO_API_KEY and KINDO_REVIEW_AGENT_ID).
3

First Launch

Log in with your credentials. The dashboard shows an overview of all applications in the pipeline. If this is a fresh install, everything will show zero — that's normal.

Start by adding your first applicant using the "+ New Applicant" button.

4

Adding Applicants

Navigate to Applicants → New Applicant. Fill in the applicant's details:

  • Name and email (required)
  • GPA on a 4.0 scale
  • Test score (SAT/ACT composite)
  • Intended major
  • Personal essay and extracurricular activities

The more data you provide, the better the AI review will be.

5

AI-Powered Reviews

On any applicant's profile page, click "Request AI Review". The Kindo AI agent evaluates the applicant across four dimensions:

  • Academic — GPA and test scores relative to major
  • Essay — clarity, authenticity, and insight
  • Extracurricular — leadership, depth, alignment
  • Overall — holistic assessment

Each is scored 1–10 with a recommendation of admit, waitlist, or deny. Without a Kindo API key configured, a mock review is generated for development purposes.

6

Manual Reviews

Scroll to the "Submit Manual Review" form on the applicant's profile page. Enter your scores (1–10 per category), select a recommendation, and add notes on strengths and concerns.

An applicant can have multiple reviews — both AI and manual — which appear side by side for easy comparison.

7

Next Steps

  • Update applicant statuses (admitted, waitlisted, denied) as decisions are made.
  • Use the dashboard to monitor your pipeline and spot bottlenecks.
  • Configure the Kindo agent for production AI reviews by setting KINDO_API_KEY and KINDO_REVIEW_AGENT_ID.

Need help? Click the ? button on any page for context-specific guidance.
